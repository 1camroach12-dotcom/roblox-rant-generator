# Roblox Rant Generator

A funny website that auto-generates dramatic Roblox rants.

## How To Use
1. Download files
2. Upload to GitHub
3. Enable GitHub Pages
4. Open your site
5. Click Generate Rant

## Deploying On GitHub Pages
1. Create a new GitHub repo
2. Upload all files
3. Go to Settings
4. Click Pages
5. Select main branch
6. Save
7. Your site goes live
